ReDuX — версия без поддержки.

В этой сборке:
- Поддержка полностью удалена из меню, HTML и JavaScript.
- Админка содержит поиск пользователей по логину и никнейму.
- Президент может назначать/снимать вице-президента и заместителя, банить и разбанивать пользователей.
- Redux и обновления сохраняются локально и синхронизируются через Supabase, если подключён config.js.
- Поиск пользователей обновляется при изменениях общей базы.

Для общего хранения пользователей/ролей/Redux/обновлений выполни supabase.sql в своём проекте Supabase.
